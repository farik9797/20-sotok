# 20 соток — макет сайта

Статический макет многостраничного сайта студии инженерного благоустройства «20 соток» (Минск и Минский район) по брифу.

Сайт: https://farik9797.github.io/20-sotok/

Локальный просмотр: `python3 -m http.server 8020` и открыть http://localhost:8020/.
