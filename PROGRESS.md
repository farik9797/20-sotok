## Статус
Готов первый статический макет сайта по брифу (7 страниц). Проверен в браузере на 1440px и 375px. Ожидает обратной связи заказчика.

## Что сделано
- Дизайн-система по брифу (стиль SEED Studio): фон `#2A2F35`, светлые секции `#EAE6DF`/`#F4F4F2`, акценты `#2B4236` (хвойный) и `#B8860B` (латунь). Шрифты Manrope (дисплейный, тонкие крупные номера блоков) + Golos Text (текст), оба с кириллицей.
- Страницы: `index.html` (6 блоков по брифу + блок «Как проходит работа»), `uslugi/plitka.html`, `uslugi/gazon.html`, `uslugi/poliv.html`, `uslugi/drenazh.html`, `proekty.html` (кейсы + слайдер «до/после» + фильтр), `blog.html`.
- Интерактивный квиз (`assets/js/quiz.js`): 3 вопроса → экран захвата (Telegram/Viber + маска +375 (__) ___-__-__) → финал. Модалка на всех страницах + встроенный на страницах услуг с предвыбором системы. Отправка в CRM не реализована (заглушка в `form.submit`).
- Плоская инфографика (SVG из примитивов): пирог основания парковка/дорожка, разрез газона с сеткой от кротов, план полива head-to-head vs «на глаз», схема дренажа с колодцем и выводом за границу участка.
- Иконки: Lucide + Simple Icons, инлайн-спрайт в каждой странице (не рисованы вручную).
- Анимации: GSAP + ScrollTrigger (появление блоков, оркестровка первого экрана), `prefers-reduced-motion` учтён.

## Стек и структура
- HTML + Tailwind (Play CDN) + `assets/css/main.css` (токены и компоненты) + `assets/js/main.js` (навигация, reveal, маска телефона, слайдер до/после, фильтр кейсов).
- Локальный просмотр: `.claude/launch.json` → конфиг `site` (python http.server, порт 8020) или просто `python3 -m http.server 8020`.
- Итоговые HTML — источник правды. Генератор страниц (Python, header/footer/quiz общие) лежал в scratchpad сессии; при правках редактировать HTML напрямую.

## Ключевые решения (и почему)
- Manrope вместо Inter/Roboto: бриф даёт их как примеры («например»), Manrope — тот же нейтральный гротеск, но с характерными тонкими начертаниями для крупной нумерации; кириллица полная.
- Зелёный `#2B4236` почти сливается с фоном `#2A2F35`, поэтому на тёмном кнопки захвата — латунь, на светлых секциях — хвойный зелёный.
- Первый экран на мобильном не фиксирован на 100vh: заголовок виден сразу под шапкой, иначе он уезжал под фолд.
- Инфографика на мобильном прокручивается горизонтально внутри рамки (min-width 720px), чтобы подписи оставались читаемыми.
